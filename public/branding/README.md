# Alrizky monogram

Original geometric A mark with a cut in its right stroke. Black, with no gradients or decorative effects.

- `alrizky-mark.svg`: transparent, scalable source asset.
- `alrizky-mark.png`: transparent 1024 × 1024 export.
- `alrizky-mark-preview.png`: black mark on white for previews.
- Header component: `src/components/brand-mark.tsx`, using the same paths in `src/lib/brand.ts`.
- Favicon, app icon, and Apple icon are generated from the same mark.

Run `npm run branding:sync` after editing `src/lib/brand.ts`. The website inverts the header mark in dark mode for contrast.
