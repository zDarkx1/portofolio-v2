# Local brand marks

- SVG path data: Simple Icons 16.35.0, CC0-1.0, generated into `src/lib/brand-icons.ts`. Each entry retains its upstream brand asset URL. Regenerate with `npm run icons:sync`.
- Lenis PNG: https://lenis.dev/apple-touch-icon.png, linked by the official https://lenis.dev/ homepage.
- Foundry PNG: https://www.getfoundry.sh/foundry-logo.png, linked by the official https://www.getfoundry.sh/ homepage.
- LinkedIn uses the existing local `[in]` SVG mark in `src/components/icons.tsx`; brand reference: https://brand.linkedin.com/.

Only selected SVG paths and the two local images are sent to visitors. The full Simple Icons catalog is a development dependency. Technology and social labels remain visible beside the decorative icons.
